# 赢在美股—绩点先锋排行榜

实时绩点排行榜系统，展示用户绩点排名和权益。

## 功能特点

- 📊 实时绩点排名
- 👑 共盈会成员标识
- 🏆 排名头衔系统（冠军、亚军、季军、前五、前十等）
- 🔍 用户搜索功能
- 📱 响应式设计

## 技术栈

- Node.js + Express
- 纯前端 HTML/CSS/JS
- CSV 数据解析

## 部署

本项目已配置 Render 部署，连接 GitHub 仓库即可自动部署。

## 数据更新

- 听课绩点：观看时长 ≥ 30 分钟，+1 绩点
- 礼物绩点：发送礼物，+1 绩点
- 大礼绩点：礼物金额 ≥ 2000，+10 绩点
- 笔记绩点：每次笔记 +5 绩点
